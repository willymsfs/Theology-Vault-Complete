# Francis's synodal reforms aim to complete, in institutional practice, paradigm shifts Vatican II had already proclaimed in text

The Synod on Synodality, curial reform, and changed episcopal appointment criteria all target exactly the gap between proclaimed and received paradigm shifts that Unit 8 identifies.
