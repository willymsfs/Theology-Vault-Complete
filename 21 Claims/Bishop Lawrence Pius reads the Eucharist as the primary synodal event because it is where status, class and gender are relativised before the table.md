# Bishop Lawrence Pius reads the Eucharist as the primary synodal event because it is where status,
class and gender are relativised before the table

If synodality is fundamentally about communion made structural, the Eucharist is not one synodal
practice among others but the source of the whole logic: distinctions that governed the assembly
outside the church door dissolve, at least in principle, at the table of the Lord. This grounds
synodality sacramentally rather than only organisationally — a council can fail to be synodal, but the
Eucharist cannot fail to enact the equality synodality is trying to institutionalise elsewhere.
