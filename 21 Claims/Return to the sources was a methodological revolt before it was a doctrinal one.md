# Return to the sources was a methodological revolt before it was a doctrinal one

Twice in the Church's history *ad fontes* has broken a reigning method: the humanists (Valla, Erasmus) set grammatical-historical exegesis against scholastic dialectic, and the *ressourcement* theologians set biblical, patristic and liturgical sources against the neo-scholastic manual. In both cases the doctrinal consequences followed the procedural break, not the reverse.
