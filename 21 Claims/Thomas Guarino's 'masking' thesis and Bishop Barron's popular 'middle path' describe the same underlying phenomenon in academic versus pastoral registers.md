# Thomas Guarino's 'masking' thesis and Bishop Barron's popular 'middle path' describe the same underlying phenomenon in academic versus pastoral registers

Both accept that some prior ordinary teaching was genuinely reversed (Guarino) or that implementation went badly wrong in places (Barron), while both still affirm fundamental doctrinal continuity — the difference is audience and vocabulary, not substance.
