# Theology Vault — Read Me First

A second brain for BTh study, built on the method in *Obsidian_Theology_Second_Brain_Method*.

## Note types (folders)
- **00 Inbox** — fleeting capture, empty weekly
- **10 Literature** — what the authors say, page-cited
- **20 Concepts** — noun hubs (Theology, Faith)
- **21 Claims** — atomic assertions in sentence form (the thinking engine)
- **30 Schemas** — the book's numbered frameworks, kept whole
- **40 MOCs** — maps of content; start here → [[Theology MOC]]
- **50 People** — theologians, Western + Indian
- **60 Documents** — DV, LG, EN — article-anchored
- **65 Bible** — passage notes
- **70 Comparative** — Indian ↔ Christian dialogues
- **80 Wisdom** — pastoral synthesis + homily log
- **90 Exam** — question banks & flashcards

## Weekly ritual (45 min, fixed day)
Empty Inbox → extract 3–7 Claims from the week's Literature → update MOCs → write 5–10 flashcards.
