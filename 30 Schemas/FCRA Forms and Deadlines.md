# FCRA Forms and Deadlines

| Form | Purpose | Deadline |
|---|---|---|
| FC-1 | Relative remittance above Rs 10 lakh | 3 months |
| FC-2 | Foreign hospitality | About 2 weeks before travel |
| FC-3A / FC-3B | Registration / prior permission | - |
| FC-3BB | Next instalment under prior permission | After 75% utilised plus field inquiry |
| FC-3C | Renewal | Within 6 months before expiry |
| FC-4 | Annual return (NIL mandatory) | **31 December** - 9 months from FY close |
| FC-6A / 6B / 6D / 6E | Name-address / objects / utilisation account / governing body | 45 days each |
| FC-6F | Purpose-and-State migration; scope change | **22 June 2027** |
| FC-7 | Surrender | Any time |

Training audio in circulation gives FC-4 as 31 July. That is wrong - it confuses FC-4 with the income-tax audit date.
