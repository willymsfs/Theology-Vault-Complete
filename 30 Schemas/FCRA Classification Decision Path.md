# FCRA Classification Decision Path

| Step | Question | Outcome |
|---|---|---|
| 0 | Directly in furtherance of a stated objective? | Yes = programme (outside cap); No = administrative (inside 20% cap) |
| 1 | Which of the five categories? | Religious / Cultural / Economic / Educational / Social |
| 2 | Which numbered Schedule item? | Cite the ID, not merely the category |
| 3a | Is the purpose on the registration certificate? | If not: 30% of amount or Rs 1,00,000 |
| 3b | Is the State on the certificate? | If not: same penalty |
| 3c | Is it within the organisation's own objects clause? | Both FCRA and the Memorandum must permit it |
| 4 | Prohibition screen | Speculative / sub-grant / outside India / personal gain / personal-name assets / proselytisation |

Step 0 is the one most often skipped and the one with financial consequences.
