# Eucharistic Semantics: Realist Versus Nominalist

A live fault line in contemporary defences of transubstantiation. **Nominalist semantics** (the inheritance of [[Ockham]] and [[John Buridan|Buridan]]) treats a noun like "bread" as a label for a bundle of observable properties — which makes transubstantiation sound like an unintelligible trick, since the properties never change. **Realist semantics** treats "bread" as naming a genuine underlying organising principle (a substantial form), not merely a description of appearances — on this view, Joshua Hochschild argues, transubstantiation is a coherent claim about a change in what a thing fundamentally *is*, which nominalist vocabulary has simply lost the resources to say.
